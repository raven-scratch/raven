The icons this demo draws, one to a line, with the Nerd Font name after it.
`font2vm.py --chars-file` reads the whole file, so the names and the `#` add
nothing: those characters are in the ASCII set whatever else is asked for.

# Material Design Icons, the one icon family outside the basic plane. `letter of`
# reads one UTF-16 code unit, so U+F0001 arrives as two halves; putting one in the
# table is what has the engine join the pair before it looks the character up.
